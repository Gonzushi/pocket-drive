# Contributing

Start with [Development](docs/development.md) and [Architecture](docs/architecture.md). AI coding assistants must also follow [AGENTS.md](AGENTS.md).

Keep changes focused, preserve existing user data and update tests/documentation with behavior changes. Do not include generated previews, account state or credentials in commits. Before submitting, format, lint, typecheck, build and run the relevant integration tests. Include what changed and the actual validation results in the commit or pull request description.
