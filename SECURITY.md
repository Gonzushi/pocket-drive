# Security

Pocket Drive is a single-administrator private workspace. All file access requires a website session or scoped API key. The personal Codex worker must stay on a private network. Do not expose account state or uploaded files through a public directory.

For a suspected vulnerability, contact the repository owner privately through an available private channel. Do not publish credentials, exploitable deployment details or document contents in a public issue. No dedicated security mailbox or response SLA is currently configured.

See [Operations](docs/operations.md) for backups, monitoring and credential handling. Keep dependencies updated and validate upgrades against the supported Node/Next.js versions.
